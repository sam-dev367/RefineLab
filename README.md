# RefineLab ⚡

A lightweight workbench utility to test, parameterize, and compare LLM prompts side-by-side using Streamlit and LiteLLM.

---

## Features

- **Dynamic Template Engine:** Write prompt templates using `{{variable}}` placeholders with auto-generated input fields.
- **Side-by-Side Model Comparison:** Run a single prompt across multiple LLM endpoints (OpenAI, Anthropic, local Ollama) simultaneously.
- **Configurable Settings:** Adjust temperature, max tokens, and system parameters on the fly.
- **Clean UI:** Powered by Streamlit for interactive prompt testing.

---

## Tech Stack

- **Language:** Python
- **Interface:** Streamlit
- **LLM Abstraction:** LiteLLM
